# IJK Coaching - Android app

**Download:** [ijk-coaching.apk](https://github.com/connectabdullahdev/ijk-app-releases/releases/latest/download/ijk-coaching.apk) (always the newest version, about 100 MB)

The official app of IJK Coaching System for students, parents and staff: attendance, results, fees, notices and the ID card.

## Install

1. Open the download link on the Android phone.
2. When the download finishes, open the file.
3. If the phone says installing from this source is not allowed: tap **Settings**, turn on **Allow from this source** (Install unknown apps) for your browser or WhatsApp, and go back.
4. Tap **Install**. If Google Play Protect warns you, tap **More details** -> **Install anyway**.
5. Open **IJK Coaching**, sign in with the login the institute gave you, and tap **Allow** for notifications.

If an older IJK app is installed, this installs over it as an update.
